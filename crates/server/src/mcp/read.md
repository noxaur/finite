Look at a design as text. Without select: an overview and every artboard's outline with ids. Start here.

select is a CSS selector; as picks "outline" (default), "html", "css", "jsx" or "computed" (what the browser resolves, like var(--bg) in Dark mode). contains: "#3b82f6" finds elements and tokens with that value, so you needn't read whole artboards. export returns a file's text, or where to download a tar. app: the whole design as a Vite + React project of the prototype flow, one route per data-route.
